# Bookworms iOS instructions

This independent repository implements Bookworms for iPhone and Mac from one target: spine generation for the Apple TV app, a 3D spine viewer, and share images. Follow the workspace `AGENTS.md` one folder up for writing, documentation, comments, and review rules.

- Target iOS 27 and later. The same target builds a native macOS 27 app for Apple silicon Macs: guard iOS-only APIs with `#if os(iOS)` or `#if os(macOS)`, add missing UIKit members to `Support/AppKitBridge.swift` instead of forking drawing code, and use `ThisDevice.name` in text that names the device. Use current SwiftUI, Swift concurrency with explicit isolation, and Swift 6 strict concurrency.
- Keep the companion read-only toward Hardcover. Its own Hardcover sign-in (OAuth device flow, read scopes only) stores the token in this device's Keychain; never sync or upload the token, and never write to Hardcover.
- Each generation run designs with the best model tier available on this device when it starts (`ModelTier`, `BookAnalyzer.bestStatus(pcc:backup:onDevice:)`): Apple's `PrivateCloudComputeLanguageModel`; else the owner's backup model, a third-party provider (Anthropic, OpenAI, Google, or an OpenAI-compatible endpoint) chosen in Settings on the Mac or the Spines tab on the iPhone; else Apple's on-device `SystemLanguageModel`; else local defaults with no model, which choose families from the book's genres (`BookAnalyzer.genreFamilies(_:)`, mirroring the tvOS app's `BookWallLocalSpine.fontName(for:)`). Every tier keeps the same palette, `TitleLettering` ranking, font checks, and validation. Designs and series looks record their tier in `provenance` (Private Cloud Compute's record no model token; without one, the generator decides: `SpineDesignV1.modelToken`), and a run replaces a weaker tier's design or unedited look but never the reader's colors or edits. A local-defaults design whose font couldn't download records `font:system` (`SpineDesignV1.awaitsFont`) and ranks below its tier until a run reaches the font. `WorkLedger` records each check's tier, so a better tier rechecks those books on its first run; keep the tier read before the queue free of model requests. Private Cloud Compute without image input counts as unavailable, and a series copy never upgrades a look. Test builds compiled with `NO_PCC` (`script/install_on_device.sh`, `script/run_mac.sh`) never create the Private Cloud Compute model and start at the backup tier. Regenerate `Bookworms/SpineFontAtlas.lzfse` with `script/spine-font-atlas.sh` after changing `SpineFamily`.
- Backup providers plug in through FoundationModels' `LanguageModel` protocol (`Services/SpineDesigner.swift`), so add model features to the shared prompts and schemas rather than per provider. Keep provider API keys in this device's Keychain (`KeychainSecret`), never synced or uploaded; a remembered rejection (`SpineDesigner.rejection`) records only whether a key exists.
- Preserve the CloudKit JSON contract in `Bookworms/Models/CloudContract.swift`. It must stay compatible with the tvOS repository's `SpineCloudStore.swift`, and the tests pin the shared digests.
- Use `project.yml` and XcodeGen for project changes. Source folders are synced, so new files need no regeneration. Run Git commands inside this folder.
- Lint edited Swift with `xcrun swift-format lint --strict` and the repository `.swift-format`. Build with `script/build_and_run.sh`. Run tests when the request calls for them.
- Use the private preview library (`script/load-preview-data.py`) for Simulator checks. It contains real reading history: keep it in `.local/` and never publish screenshots made from it. Tests use fictional fixtures.
- Unsigned or Simulator builds prove compilation and local rendering only. iCloud access, push delivery, background scheduling, and Private Cloud Compute quotas need a signed device build.
